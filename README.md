# Richard Priest: IT Director profile for Perch Group

A short, single-page profile for the Perch Group IT Director role (hybrid, Manchester Spinningfields and Blackpool).

Styles are in `assets/site.css`; `assets/site.js` adds the nav, footer, theme switch, print, progress bar, back-to-top and copy-email button. `assets/Richard_Priest_CV.docx` is the public, phone-free CV.

Run locally: `python -m http.server 8930 --directory .` then open http://localhost:8930
